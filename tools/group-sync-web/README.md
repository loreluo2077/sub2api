# Sub2API 分组同步 Web 工具

本地运行的多上游数据控制台。使用普通用户账号登录多个 Sub2API 站点，聚合用户、余额、API Key 摘要、分组、渠道、模型、用量、订阅和监控数据并导出 JSON。

```bash
node tools/group-sync-web/server.mjs
```

浏览器打开 `http://127.0.0.1:4178`。可通过 `GROUP_SYNC_PORT` 修改端口。

密码、访问令牌和两步验证临时令牌只保存在本次请求内存中。浏览器保存供应商名称、目标地址、邮箱和脱敏后的聚合结果，刷新页面后仍可查看。API Key 在聚合结果中默认脱敏。
