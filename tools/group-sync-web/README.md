# Sub2API 分组同步 Web 工具

本地运行的多上游数据控制台。使用普通用户账号登录多个 Sub2API 站点，查看余额、分组、用量等数据；为上游每个分组生成一把绑定该分组的 Key，再在目标站点把上游 Key 导入自己的账号。

```bash
node tools/group-sync-web/server.mjs
```

浏览器打开 `http://127.0.0.1:4178`。可通过 `GROUP_SYNC_PORT` 修改端口。

## 持久化范围

- **只持久化账户数据**：站点配置（名称/地址/邮箱/密码 **或凭据 Token**，明文）+ 账户摘要（余额、用户名、最后刷新时间），保存在本地 SQLite `tools/group-sync-web/data.db`（已加入 `.gitignore`）。
- 分组、API Keys、用量、订阅等**不落库**，每次查看/刷新时实时登录拉取。
- 生成的 Key 明文仅存在于本次会话，不持久化。

## 登录方式（两种）

每个站点可二选一：

1. **账号密码**：填登录邮箱 + 密码。适合站点未开启验证码的情况。
2. **凭据（Token）**：填登录后的 `access_token`（JWT）。适合站点开启验证码、直接密码登录不通的情况——先在浏览器登录上游站，再按下面方法取 token 粘贴进来。

> **如何获取 Token**：打开上游站点登录页 → 登录成功进入站点 → 按 `F12` 打开开发者工具 → 切到 **Console** 标签 → 粘贴下面脚本回车：
> ```js
> localStorage.getItem('auth_token') || localStorage.getItem('access_token') || localStorage.getItem('token') || sessionStorage.getItem('auth_token') || sessionStorage.getItem('access_token') || sessionStorage.getItem('token')
> ```
> 复制输出的字符串粘贴到工具里。若返回 null：F12 → Network → 保留日志 → 站内任意请求 → 复制请求头 `Authorization: Bearer xxx` 里的 `xxx`。
>
> Token 会过期（站点 JWT 有效期），过期后需重新获取。工具内每个 Token 输入框旁都有「如何获取？」折叠面板提示。

## 用法

1. **添加上游站点**：侧边栏「上游站点」右侧 `+`，填写名称、站点地址、选择登录方式（密码或 Token）、填对应凭据后，可先点「测试连接」验证再「保存并刷新」。
2. **添加目标站点**：侧边栏「目标站点」右侧 `+`，填写自己应用的账号信息并保存。
3. **上游 · 分组建Key**：选中上游站点 → 「分组建Key」，三步向导：连接上游 → 选择分组（可筛「只看无 Key」，设命名前缀）→ Key 预览（每个分组确保一把绑定该分组的 Key，已有则复用）。生成的 Key 仅在会话内，可点击显示或导出。
4. **目标 · 导入账号**：选中目标站点 → 「导入账号」，选择来源上游（服务端实时登录上游拉取当前 Keys），用穿梭框选全部或逐个，导入目标账号（目标用已存密码/Token 自动登录，已存在相同 Key 自动跳过），结果在对话框内汇总。

## 说明

- 切换站点时会自动实时刷新该站点数据；「刷新数据」可手动重新拉取。
- 删除站点会一并清理其本地账户数据。
